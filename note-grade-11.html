例题与解析（全量）

1. 下列数中哪些是负数：-3，0，+2.5，-1/2？（把所有负数依次写出来，用逗号隔开）　[数学·正数与负数的概念]
答案：-3，-1/2
解析：负数是小于 0 的数，前面带“-”号且不为 0。-3 和 -1/2 是负数；0 既不是正数也不是负数，+2.5 是正数。
2. 下列关于 0 的说法中，正确的是哪一个？　[数学·正数与负数的概念]
答案：B
解析：0 是正数与负数的分界，既不是正数也不是负数。
3. 若向东走 5 m 记作 +5 m，则 -3 m 表示什么？（选择正确答案）　[数学·用正负数表示相反意义的量]
答案：D
解析：正负号表示相反的方向：向东为正，则负号表示向西，数值 3 表示走了 3 m，即向西走 3 m。
4. 某地规定海拔高于海平面记为正，海拔 +120 m 表示高于海平面 120 m。那么低于海平面 35 m 的地方应记作多少 m？　[数学·用正负数表示相反意义的量]
答案：-35
解析：高于为正，则低于为负，低于海平面 35 m 记作 -35 m。
5. 把 -2，0，3.5，-1/3，7 按正数、0、负数分类。（分三类写出每类包含的数）　[数学·有理数的分类]
答案：正数：3.5，7；0：0；负数：-2，-1/3
解析：大于 0 的是正数：3.5，7；等于 0 的是 0；小于 0 的是负数：-2，-1/3。
6. 下列各数中，不是有理数的是哪一个？　[数学·有理数的分类]
答案：A
解析：有理数包括整数和分数（有限小数、无限循环小数），π 是无限不循环小数，不是有理数。
7. 画数轴缺少哪一要素就不合格：只有原点和正方向？　[数学·数轴]
答案：B
解析：数轴的三要素是原点、正方向、单位长度，题中已有原点和正方向，所以缺少单位长度。
8. 数轴上，原点左侧 2 个单位长度处的点表示的数是多少？　[数学·数轴]
答案：-2
解析：原点左侧为负方向，距离原点 2 个单位，表示 -2。
9. 在数轴上标出 -1.5 和 2 的位置，哪个更靠右？（只写出这个数）　[数学·在数轴上表示有理数]
答案：2
解析：数轴上右边的点表示的数大于左边的点，2 > -1.5，所以 2 更靠右。
10. 数轴上点 P 表示 -2，把点 P 向右移动 5 个单位长度得到点 Q，则点 Q 表示的数是多少？　[数学·在数轴上表示有理数]
答案：3
解析：向右移动是加：-2+5=3。
11. 求 -7 和 3/4 的相反数，并化简 -(-5)。（依次作答，用逗号隔开）　[数学·相反数]
答案：7，-3/4，5
解析：只有符号不同的两个数互为相反数：-7 的相反数是 7，3/4 的相反数是 -3/4；-(-5) 是 -5 的相反数，等于 5。
12. 下列各组数中，互为相反数的是哪一组？　[数学·相反数]
答案：D
解析：互为相反数要求只有符号不同。0.5 与 -1/2 绝对值相同符号相反；2 与 1/2、-3 与 1/3 是倒数关系或既非相反也非倒数；-(-4)=4，两数相等。
13. |-4| 与 |4| 分别是多少？（依次作答，用逗号隔开）　[数学·绝对值的概念与几何意义]
答案：4，4
解析：绝对值是数轴上点到原点的距离，-4 与 4 到原点的距离都是 4。
14. 数轴上表示 -7 的点到原点的距离是多少个单位长度？　[数学·绝对值的概念与几何意义]
答案：7
解析：绝对值的几何意义：|-7| 就是表示 -7 的点到原点的距离，等于 7。
15. 若 |x|=3，求 x。（有几个值就写几个，用逗号隔开）　[数学·绝对值的化简与计算]
答案：3，-3
解析：绝对值等于 3 的数有两个，它们互为相反数：3 和 -3。
16. 计算 |-12|-|5|+|0| 的值。　[数学·绝对值的化简与计算]
答案：7
解析：|-12|=12，|5|=5，|0|=0，所以 12-5+0=7。
17. 比较 -2/3 与 -3/4 的大小。（选择正确结论）　[数学·有理数的大小比较]
答案：A
解析：两个负数比较，绝对值大的反而小。2/3=8/12 小于 3/4=9/12，所以 -2/3 > -3/4。
18. 在 -5，-1，0，3 这四个数中，最小的数是多少？　[数学·有理数的大小比较]
答案：-5
解析：负数小于 0 小于正数；两个负数中绝对值大的反而小，|-5|>|-1|，所以 -5 最小。
19. 计算 (-8)+5 和 (-3)+(-4)。（依次作答，用逗号隔开）　[数学·有理数的加法法则]
答案：-3，-7
解析：异号两数相加，取绝对值较大的数的符号，再用较大的绝对值减较小的：-(8-5)=-3；同号相加取相同符号，绝对值相加：-(3+4)=-7。
20. 下列计算正确的是哪一个？　[数学·有理数的加法法则]
答案：D
解析：(-2)+5：异号相加，取 5 的符号（正），5-2=3。其余三式符号或数值有误：(-5)+3=-2，(-5)+(-3)=-8，4+(-9)=-5。
21. 简便计算 (-7)+12+(-3)+8。　[数学·加法运算律与简便运算]
答案：10
解析：把同号的数结合：[(-7)+(-3)]+(12+8)=-10+20=10。
22. 等式 13+(-7)+(-13)=13+(-13)+(-7) 主要运用了哪条运算律？　[数学·加法运算律与简便运算]
答案：B
解析：只是交换了 (-7) 与 (-13) 的位置，没有改变加数的分组，所以用的是加法交换律。
23. 计算 3-(-5) 和 (-2)-7。（依次作答，用逗号隔开）　[数学·有理数的减法法则]
答案：8，-9
解析：减去一个数等于加上它的相反数：3-(-5)=3+5=8；(-2)-7=(-2)+(-7)=-9。
24. 计算 (-4)-(-9)。　[数学·有理数的减法法则]
答案：5
解析：(-4)-(-9)=(-4)+9=5。
25. 计算 -3+8-(-2)-5。　[数学·有理数的加减混合运算]
答案：2
解析：先化为省略括号的和：-3+8+2-5，再计算：（-3-5）+（8+2）=-8+10=2。
26. 计算 (-4)-(-6)+(-3)。　[数学·有理数的加减混合运算]
答案：-1
解析：减法化为加法：(-4)+6+(-3)=-4+6-3=-1。
27. 计算 (-3)×(-4) 和 (-5)×2。（依次作答，用逗号隔开）　[数学·有理数的乘法法则]
答案：12，-10
解析：同号两数相乘得正，绝对值相乘：(-3)×(-4)=12；异号得负：(-5)×2=-10。
28. 下列各式中，结果为正数的是哪一个？　[数学·有理数的乘法法则]
答案：D
解析：同号两数相乘得正数，(-2)×(-3)=6；(-2)×3 与 2×(-3) 异号得负，0×(-3)=0。
29. 用分配律计算 (-12)×(1/2-2/3+1/4)。　[数学·乘法运算律与多个因数相乘]
答案：-1
解析：(-12)×1/2+(-12)×(-2/3)+(-12)×1/4=-6+8-3=-1。
30. (-2)×3×(-4)×(-5) 的积是什么？　[数学·乘法运算律与多个因数相乘]
答案：C
解析：几个非零因数相乘，负因数有 3 个（奇数个），积为负数；绝对值 2×3×4×5=120，所以积为 -120。
31. 求 -2/5 的倒数。　[数学·倒数]
答案：-5/2
解析：乘积为 1 的两个数互为倒数，(-2/5)×(-5/2)=1，所以倒数是 -5/2（倒数与原数符号相同）。
32. 求 -4 的倒数。　[数学·倒数]
答案：-1/4
解析：(-4)×(-1/4)=1，所以 -4 的倒数是 -1/4。
33. 计算 (-12)÷(-3/4)。　[数学·有理数的除法]
答案：16
解析：除以一个数等于乘它的倒数：(-12)×(-4/3)=16。
34. 计算 (-18)÷6。　[数学·有理数的除法]
答案：-3
解析：异号两数相除得负，绝对值相除：18÷6=3，所以结果是 -3。
35. 计算 -6÷(-2)×3+(-4)。　[数学·有理数的加减乘除混合运算]
答案：5
解析：先乘除后加减，乘除按从左到右：(-6)÷(-2)=3，3×3=9，9+(-4)=5。
36. 计算 8-12÷(-3)。　[数学·有理数的加减乘除混合运算]
答案：12
解析：先算除法：12÷(-3)=-4，再算 8-(-4)=12。
37. 写出 (-3)³ 与 -3³ 的含义并计算。（只需依次写出两个式子的值，用逗号隔开）　[数学·乘方的概念]
答案：-27，-27
解析：(-3)³ 表示 3 个 (-3) 相乘，=(-3)×(-3)×(-3)=-27；-3³ 表示 3³ 的相反数，=-(3×3×3)=-27。
38. 在幂 (-5)³ 中，底数是哪一个？　[数学·乘方的概念]
答案：A
解析：括号内的 -5 是相同因数，即底数；3 是指数。
39. 计算 (-2)⁴ 和 (-1/2)³。（依次作答，用逗号隔开）　[数学·乘方的运算与符号规律]
答案：16，-1/8
解析：负数的偶次幂为正：(-2)⁴=16；负数的奇次幂为负：(-1/2)³=-1/8。
40. 下列各数中，结果为负数的是哪一个？　[数学·乘方的运算与符号规律]
答案：C
解析：负数的奇次幂是负数：(-2)³=-8；(-3)²=9，(-1)⁴=1，0⁵=0。
41. 计算 -2²+(-3)²÷(-3)。　[数学·含乘方的有理数混合运算]
答案：-7
解析：先算乘方：-2²=-4，(-3)²=9；再算除法 9÷(-3)=-3；最后 -4+(-3)=-7。
42. 计算 (-3)²-2×5。　[数学·含乘方的有理数混合运算]
答案：-1
解析：先乘方 (-3)²=9，再乘 2×5=10，最后 9-10=-1。
43. 把 3 450 000 用科学记数法表示。（选择正确的一项）　[数学·科学记数法]
答案：C
解析：科学记数法 a×10^n 要求 1≤|a|<10。3 450 000 小数点向左移 6 位得 3.45，所以是 3.45×10^6。
44. 把 8 600 000 用科学记数法写成 a×10^n（1≤a<10）的形式，则 n 等于多少？　[数学·科学记数法]
答案：6
解析：8 600 000=8.6×10^6，所以 n=6。

答案：2
解析：0.03586 精确到 0.001 得 0.036，从左边第一个不是 0 的数字 3 起到末位：3，6，共 2 个有效数字。

答案：5

答案：2
解析：二进制只用 0 和 1 两个数码，每满 2 就向前一位进 1，即逢二进一。
49. 用字母表示加法交换律。　[数学·用字母表示数]
答案：a+b=b+a
解析：加法交换律指两个数相加，交换加数的位置，和不变，用字母 a、b 表示为 a+b=b+a。
50. 一本书的价格是 a 元，买 5 本这样的书一共需要多少元？　[数学·用字母表示数]
答案：D
解析：总价=单价×数量，所以 5 本书共 5×a=5a 元。

答案：3ab
解析：a 与 b 的积是 ab，它的 3 倍是 3×ab，数字与字母相乘省略乘号且数字写在前面，写成 3ab。

答案：2x-5
解析：x 的 2 倍是 2x，与 5 的差是 2x-5（被减数是 x 的 2 倍）。
54. “比 m 大 7 的数”用代数式表示为哪一个？　[数学·列代数式]
答案：C
解析：比 m 大 7，就是在 m 的基础上加 7，所以是 m+7。
55. 说明 100-5t 在“用水量问题”里可能的含义。　[数学·解释代数式的实际意义]
答案：如：水箱原有 100 L 水，每分钟流出 5 L，t 分钟后剩余的水量（L）。
解析：100 是原有水量，5t 是 t 分钟共流出的水量（每分钟 5 L），两者相减就是剩余水量。
56. 若 a 表示一个正方形的边长（单位：cm），则代数式 4a 表示这个正方形的什么？　[数学·解释代数式的实际意义]

答案：2n+1
解析：相邻两项都相差 2，首项为 3，所以第 n 项为 3+2(n-1)=2n+1。
58. 数列 3，5，7，9，… 的第 n 项是 2n+1，则第 20 项是多少？　[数学·用代数式表示规律]

答案：14

答案：11
