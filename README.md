# K-12 学霸笔记站点

**GitHub 仓库：** https://github.com/awakeninglanxin/k12-xueba-notes

**在线浏览：** https://awakeninglanxin.github.io/k12-xueba-notes/

按 14 个年级（幼儿 0-3 岁 → 小班 / 中班 / 大班 → 小学一至六年级 → 初一 / 初二 / 初三 → 高中）组织的静态学习资料站点。全部内容取自真实公开数据源与 ima 知识库检索结果，**未编造知识点或题目**。

- **44 个 HTML 页面**：1 个总入口 + 14 个年级精讲页 + **14 张思维导图** + 14 个完整笔记页 + 1 个来源说明页
- **3297 个知识点**（含年级、章节、描述、掌握标准、诊断题）
- **13335 道带解析题目**，每个年级抽取 60 道例题（精讲页 20 道 + 笔记页 40 道，两页不重复）
- **339 条 ima 教辅目录索引**，按年级拆分
- **三页分工、内容零重复**：同一份知识点正文与题目只在一个页面出现
- 白底黑字、纯静态、无外部依赖，可完全离线使用

## 一、快速开始

| 方式 | 操作 |
|---|---|
| 在线 | 打开 https://awakeninglanxin.github.io/k12-xueba-notes/ |
| 本地双击 | 直接打开根目录 `index.html`（页内链接均为相对路径） |
| 本地服务 | `python -m http.server 8000` 后访问 `http://localhost:8000` |

> 根目录 `.nojekyll` 用于关闭 Jekyll 处理，保证 `_生成工具/` 等下划线目录与中文路径在静态服务下可正常访问。线上由 `.github/workflows/pages.yml` 通过 GitHub Actions 部署，每次推送到 `main` 自动更新站点。

## 三、页面分工与去重

每个年级 3 个页面，同一份实质正文只在其中一页出现，其它页只放导航链接、结构名称或统计数字。

| 页面 | 独有内容 | 刻意不放 |
|---|---|---|
| 精讲页 `grade-XX.html` | 知识结构统计表、学前发展目标全文、20 道基础自测、三页导航 | 知识点正文、进阶例题、教辅清单、脑图 |
| 思维导图 `map-grade-XX.html` | 放射状 SVG 脑图、章节树、知识点名称索引 | 知识点正文、题目、教辅清单、发展目标全文 |
| 完整笔记 `note-grade-XX.html` | 全部知识点正文 + 掌握标准 + 自测题、40 道进阶例题、ima 教辅清单 | 基础自测 20 道、发展目标全文、结构统计表 |

改造前后实测（按页面解析统计）：

| 重复指标 | 改造前 | 改造后 |
|---|---:|---:|
| 精讲页 vs 笔记页 · 知识点正文 | 400 块 | 0 |
| 精讲页 vs 笔记页 · 例题 | 200 道 | 0 |
| 精讲页 vs 笔记页 · 发展目标 | 72 条 | 0 |
| 学前 4 页共用同一组先修知识点 | 24 处 | 0 |
| 同一知识点 id 出现在多个年级 | 0 | 0 |
| 思维导图页数 | 0 | 14 |

具体处理：① 精讲页删除「每科前 8 个知识点精讲」，改为学科 / 领域 / 章节统计表；② 60 道例题按 20 / 40 拆给两页，零交集；③ 学前发展目标全文只留精讲页；④ 学前 4 页的启蒙资源与一年级先修知识点按年龄段切片，互不重复，且先修只列名称并链接到一年级笔记正文；⑤ 总入口的来源表精简为一句话并指向 `sources.html`。脑图页只列知识点名称，不复制正文；学前脑图外圈只取每条目标前 8 字作关键词索引。

> `资料库/年级笔记/*.md` 是完整笔记网页版的 Markdown 离线归档（同一份笔记的另一种格式），供本地打印与二次编辑，不属于站内页面重复。ima 目录索引中有 90 条教辅同时归属多个年级，属目录复用，非正文复制。

## 六、本地复现

```bash
python _生成工具/build_site.py
```

生成脚本已按模块拆分，每个文件都控制在 20 KB 以内：

| 模块 | 职责 |
|---|---|
| `build_site.py` | 入口，只做调度 |
| `site_core.py` | 常量 / 数据加载 / 样式 / 页面骨架 / 工具函数 / 页面分工契约 |
| `site_mindmap.py` | 放射状 SVG 脑图 + 树状知识地图 |
| `site_pages.py` | 总入口 / 精讲页 / 思维导图页 / 来源页 |
| `site_notes.py` | 完整笔记网页版 + Markdown 归档 |

`build_site.py` 只读取 `资料库/` 中已归档的数据，可反复重跑，覆盖生成 44 个 HTML、`style.css` 与 14 份 Markdown 笔记。

`prepare_data.py` 负责从零归档三类来源，重跑前需要重新通过 ima MCP 检索并保存结果、下载开源仓库 zip 与学前指南 PDF。详见 `_生成工具/README.md`。

## 八、已知限制

1. ima MCP 的 `FetchMediaContent` 对订阅知识库一律返回 `220030 该文件获取失败`，因此 PDF 原件与全文无法导出，本仓库只保留目录索引。
2. 部分本地预览面板不提供 `.md` / `.pdf` 的在线渲染，因此每份笔记额外生成了 HTML 网页版；Markdown 与 PDF 保留在 `资料库/` 供本地使用（GitHub Pages 上这两类文件均可直接访问）。
3. 知识点覆盖以数学为主，兼有语文、英语、物理、化学、科学、道法、历史、地理、生物；各科覆盖年级不同，详见各年级页面。
4. 数据源中有 44 组「同名但不同 id」的知识点分布在不同年级（如二年级科学「我们周围的空气」与初三化学同名），属真实学科编排，不是页面复制。
